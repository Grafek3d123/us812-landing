## ⚙️ Что правится часто

### Цена золота (секция «Ваш металл»)
`js/config.js` — правится вручную, после изменения задеплоить:
```js
goldPrice999PerGram: 14641,   // 999,9 с НДС, источник «Регион-Золото»
goldPrice585PerGram: 8565,    // = 999 × 0.585
goldPriceNote: '…от 11.09.2026'  // дата актуальности в подписи
```
Обновлять раз в 2–4 недели.

### Отзывы
Скинуть новые скриншоты → положить в `assets/images/reviews/` → карточка по образцу
`review-card--screenshot` в секции reviews.

### FAQ
Вопросы — в секции `faq` (index.html), аккордеон работает из `main.js`
(класс `active`). Первоисточник ответов — `ASKQUERY-FAQ-answers.md`.

### Форма заявки (Web3Forms)
Получатель письма задаётся на стороне Web3Forms и привязан к access key —
в коде адреса нет. Ключ и endpoint лежат в скрытых полях формы `#contactForm`
(index.html): `access_key`, `subject`, `from_name`, `redirect`, honeypot `botcheck`.
Смена получателя = новый access key → поменять одно значение в index.html.
Отправка и обработка ответа — `js/main.js` (submit-хендлер): успех засчитывается
только при `response.ok` + `data.success`, иначе показывается блок `#formError`
с tel/VK. Бэкенд не нужен — GitHub Pages статический.

**Тариф бесплатный, лимит 250 заявок в месяц** (остаток виден в дашборде Web3Forms;
на 12.09.2026 — 248/250, две ушли на тесты: базовая отправка и отправка с полем-ссылкой
на фото). На 251-й заявке сервис перестаёт принимать
заявки до начала следующего месяца, и форма честно покажет `#formError` — это не баг кода,
а конец квоты. 250/мес ≈ 8 заявок в сутки, при текущем трафике запас не выбран.
